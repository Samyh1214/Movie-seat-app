# Movie-seat-app

## Projektbeskrivning

En enkel bokningsapplikation som använder Json Server som ett mock-API för att hämta filmer från en lokal JSON-databas. Appen inkluderar enkel selektion för att toggla säten och uppdaterar dynamiskt pris för vald film och antal valda säten.
